## 회귀 과정에서 해결한 문제

1. 학습 원천자료 열람 중 일반 작업 환자가 바뀌는 문제 → 학습 전용 자료 브라우저에서 현재 환자 선택 보존.
2. `ISS-plan-med-original`처럼 계획 검토에만 속한 이슈를 A2 미확인 원자료로 잘못 해석하는 문제 → A2 실제 영역 여부 확인 후 차단 판단.
3. A2 변경 미인계 차단 항목을 클릭해도 A2로 이동하지 않는 문제 → 평가 수정 및 인계 화면으로 이동하도록 변경.
4. 390px에서 상단 `초기화` 텍스트가 줄바꿈되는 문제 → 버튼 `nowrap`, breadcrumb 너비 조절.
5. A2 상충을 원천자료 연결만으로 승인 우회할 가능성 → 상충 원래 평가값이 변경·인계되지 않았다면 계속 HARD 차단.

**범위:** 자동 테스트는 상호작용과 내부 도메인 상태를 검증하되 실제 의료 판단, 서식 타당도, 보안 인증 및 서버 발행을 검증하지 않습니다.
