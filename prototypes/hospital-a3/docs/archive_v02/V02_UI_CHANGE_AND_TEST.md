# A3 v0.2 UI 개선·기능 검증

## 사용자 피드백과 대응

| 피드백 | v0.2 조치 |
|---|---|
| 임상 위험도/목업/A2 규칙/시연 설명이 메인에 중복 | `사용 안내` 대화창에 집중. 일부 기능적 상태(필수 확인·발행 차단)만 작업 화면에 유지 |
| 글씨가 작고 정보량이 많음 | 본문 14–16px 중심, 제목 16–37px. 6개 편집 카드는 접힌 상태에서 확인 여부만 개괄, 첫 카드만 펼침 |
| 환자 미리보기 공간 부담 | 우측 미리보기 접기→편집 패널 전체 폭, B 메뉴의 독립 전체 화면 제공 |
| 환자 목록·A2 메뉴 비작동 | A1 선택 팝업과 A2 30필드 평가 화면, 명시적 A2→A3 스냅샷 인계 추가 |
| 발행 차단 배너의 행동 부재 | 버튼/대화창/항목별 탐색·자동 펼침·포커스 이동 추가 |

## 기능 설계 주의

- 인계 전 A2 입력 변경은 A3 발행본에 반영되지 않음. 명시적 인계 시 A3 검토·확인 상태를 무효화하며, 이미 발행된 계획은 인계할 수 없음(개정 먼저 필요).
- A1·A2는 이 독립 A3 프로토타입 안에서 구현된 연결 실험 UI. 승인된 원래 A2 v0.5 화면의 기능과 스타일을 완전히 복제·통합한 것은 아님.
- 원본 A2 GitHub 파일, 평가 규칙, 환자용 v1.2는 변경 없음.
- 발행 전 검증을 우회하거나 자체 업무 점수를 임상적으로 검증된 척도처럼 사용하지 않음.
