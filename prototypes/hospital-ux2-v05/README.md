# 의료진 UX 2.0 v0.5 · 나의 퇴원안내 환자 앱 개선

별도 개발 브랜치 \`feat/hospital-ux2-v05\`. 기존 main / gh-pages 운영 배포와 자료는 변경하지 않는다.

## 의료진
- \`prototypes/hospital-ux2-v05/index.html\`은 독립 HTML. PC에서 87px 접이식 사이드바(아이콘 + 짧은 텍스트 + 전체 제목 접근성)를 제공한다.
- 모바일에서는 메뉴 버튼과 슬라이드식 전체 메뉴로 전환되며, 닫힌 메뉴는 키보드 탐색에서 제외한다.
- 원본 A2 6×5 평가를 유지한다. \`file://\`에서는 평가 시연만 가능하며 저장하지 않는다.
- 동일 출처의 HTTP(S) 경로에서 \`../integrated-v10/shared/evaluation-edit.js\`와 \`a3/storage.js\`를 읽은 뒤 **명시적으로 사용자가 'A2 평가 편집·저장'을 선택했을 때만** 합성 A2 평가 저장 및 평가 인계가 가능하다.
- 저장은 원본 저장 키/원본 트랜지션 및 compare-and-write 규칙을 사용한다. 평가 변경 시 승인 무효화, 인계 시 기존 확인 기록 재검토, 발행본 불변을 보존한다.
- A3 최종 검토·승인·발행·개정·철회는 여전히 원본 시스템 담당. v0.5 화면에서 자체 구현했다고 주장하지 않는다.

## 환자
- 운영 이름 후보 **‘나의 퇴원안내’** (고령층 이해도를 위해 직관적 한글). 변경은 환자 화면의 표기·메뉴·전환 동작에 한정한다.
- 원본 환자 UI의 하단 5개 메뉴·큰 글씨 기능·저장/공개 조건·발행본 보호 규칙을 유지한다.
- 데스크톱 접이식 91px 메뉴, 모바일 전체 메뉴 드로어(하단 5개 탭 유지).
- 화면 간 이동은 260ms opacity만 사용. 같은 화면의 콘텐츠 조작에는 과도한 이동 애니메이션 없음. \`prefers-reduced-motion\` 지원.
- 별도의 UX 선호 키만 사용한다. 환자 데이터 또는 승인 발행 기록은 수정하지 않는다.

실제 환자/의료진 사용성, 운영기기, 인증·EMR·정식 서비스 운영은 아직 검증하지 않았다.
