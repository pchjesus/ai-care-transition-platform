환자·보호자용 나의 퇴원안내

같은 최신 디자인을 두 가지 방법으로 체험할 수 있어요. 연동형은 의료진이 발행한 계획만 표시하고, 독립 예시는 별도 발행 없이 살펴볼 수 있습니다.

의료진 발행본 연동승인·발행된 안내 확인 · 미발행 시 빈 화면↗최신 독립 예시이정희님 합성 사례 · 발행 작업 없이 체험↗

서비스는 이렇게 연결됩니다

  1. STEP 01환자·입원건 확인합성 환자와 해당 입원건 선택
  2. STEP 02다영역 평가6개 영역의 업무 검토 우선도 확인
  3. STEP 03근거·승인·발행직종별 확인과 최종 승인 후 발행
  4. STEP 04나의 퇴원안내유효한 발행본을 환자 화면에 제공

실제 발행 기록이 없는 경우 연동형 환자 앱이 빈 안내를 표시하는 것은 정상입니다. 독립 예시는 별도의 합성 시나리오로 의료진 발행본과 혼합되지 않습니다.

합성 데이터 시연용 · 실제 환자정보, 의료기관 인증, EMR 연동, 임상적 정확성 검증 또는 공식적인 진료·예약이 아닙니다. 동일 브라우저·출처에서 저장·발행 상태가 연결되며, 실제 환자 공개나 서버 데이터 동기화 기능은 제공하지 않습니다.
