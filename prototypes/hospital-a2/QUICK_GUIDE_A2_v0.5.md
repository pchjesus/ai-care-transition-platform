# A2 병원용 평가 목업 — 1페이지 빠른 사용 안내 (v0.5)

> **연구·창업 과제용 시연** · 완전한 가상 환자 3명만 사용. 실제 퇴원허가·간호지시·의뢰·정식 선별/청구에 사용하지 마세요.

## 1분 안에 시연하기

1. `preview.html`을 열고 오른쪽 위 **환자 선택**에서 원하는 가상 환자를 고르세요.
2. 환자 아래 **판단과 우선 확인사항**에서 현재 선택한 영역의 등급과 필요한 확인 내용을 읽으세요.
3. 아래 **평가영역**에서 `기능`, `약료`, `사회환경` 등 원하는 영역을 선택하세요.
4. **입력값을 변경하면 결과에 반영됩니다.** 중앙에서 필수/추가 항목의 선택값을 바꾸면 위쪽 판단·영역 표시·등급이 **즉시 갱신**됩니다. `미확인`/`상충`을 선택해 자동 보류도 확인해 보세요.
5. **입력 기준·참고사항** 또는 **세부 판단 근거·참고자료**를 펼쳐 규칙과 문헌의 관계를 확인하세요.
6. **A3 검토 초안 보기**로 전달 초안을 확인하세요. 실제 승인·발행 기능이 아닙니다.

## 읽는 방법

| 표시 | 뜻 |
|---|---|
| 0~3 | **목업 자체 규칙**에 따른 업무 검토 우선도; 재입원 위험 예측·공적 등급 아님 |
| 미평가 | 필수정보 부족, 무조건 안전/0점 아님 |
| 상충 | 기록 불일치, 원천 확인 전 등급 보류 |
| 우선 확인사항 | 현재 입력값에서 확인해야 할 사항, 공식 임상 권고 아님 |
| 출처·규칙 ID | 근거의 추적을 위한 시연 정보; 특정 규칙의 임상 타당도 입증 아님 |

**데이터 저장:** 변경은 화면을 연 동안에만 남습니다. 새로고침하면 시연 초기값으로 돌아갑니다. `샘플 초기화`로 현재 환자의 값을 재설정할 수 있어요.

**아직 없는 기능:** 실환자 인증·EMR 연동·병원 승인·환자 앱 실발행·지역기관 실제 전송·AI 예후 예측.

## 목업 표기·안전 및 해석 설명 (화면에서 분리)

- 모든 환자·항목은 **합성 시나리오**, 실제 환자 데이터 사용 금지. `SYN-001` 같은 ID·`가상` 표시는 화면에서도 유지.
- 필수 입력 3/3은 **문항 입력 완결성**을 의미할 뿐 의료진 평가 완료 또는 안전 확인이 아님.
- 자체 0~3 등급은 업무 검토 우선도 시연값으로, 검증된 임상척도·재입원 위험 확률·공식 통합돌봄 선별 결과·퇴원 허가 기준이 아님.
- 판단 근거에 보이는 규칙 ID는 설계용 참조이며 임상적으로 확정된 판단 기준이 아님.
- 환자별 `미평가`·`상충`은 실제 데이터 확인 작업이 남았다는 의미이며 0으로 치환하지 않음.
- A1 환자 목록, A3 계획 초안, 입력 변경·초기화만 시연함. 실제 승인·환자용 발행·EMR·외부 기관 연동은 지원하지 않음.
- 입력값 수정은 브라우저 메모리에만 존재하고 새로고침 시 초기화됨. 별도의 실제 환자 데이터 저장이나 기관 전송은 절대 수행하지 않음.
- `등급 기준 보기`는 입력 담당자의 업무 해석을 위한 간단한 기능 설명이다. 실제 검증 제약은 이 설명서를 참조.

### UI 브랜드·화면 기준
병원용 사이드바는 다크 포레스트 그린(배경 `#214B3B`)을 유지하고, `D.` 로고는 **흰 배경·녹색 문자로 반전**하여 구분합니다. 환자 앱은 별도 화면·저장소로 유지됩니다.

### 사이드바 사용법
PC에서 왼쪽 상단 `‹` 버튼으로 접고 `›`로 펼쳐. 접은 상태는 A1/A2/A3 약자로만 표시되며, 버튼을 마우스로 가리키면 전체 메뉴가 나타나고 키보드/스크린리더에서는 접근 가능한 이름으로 읽힌다. 접고 펴더라도 환자 선택·평가 입력은 변하지 않는다. 800px 이하에서는 가로 상단 내비게이션으로 자동 전환된다.
