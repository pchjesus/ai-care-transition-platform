# 병원용 A2 · 6개 영역 최소입력/규칙 설계 v0.1

**2026-10-20 | 합성 환자·디자인 목업 | 실제 임상 성능/진료 적용 검증 전**

## 1. 목적과 기준

목표: 고령 근골격계 질환 퇴원환자의 자료를 의료진이 빠르게 확인하고, 추가로 확인하거나 지원할 항목을 식별해 A3 퇴원계획 초안으로 전달한다.

- **A1:** 환자/입원 건별 업무 확인 → **A2:** 영역별 확인 + 근거 추적 + 누락/상충 표시 → **A3:** 의료진이 검토하는 계획 초안 → **B:** 승인받은 계획만 환자에게 공개.
- **시연용 A2 등급 = 업무 검토 우선순위**. 질환 중증도, 낙상 확률, 재입원/사망 위험, 공식 정부 선별, 퇴원 허가 여부와 무관.
- **공식 퇴원환자 통합돌봄 선별 6문항과 자체 관리 필요도 6영역을 혼합하지 않는다.** 2026년 1월 보건복지부 배포 매뉴얼의 실제 선별/환자평가 업무는 별도 R01 서식 매핑이 필요하다.
- 실제 임상척도의 질문/점수/절단값을 자체 재현하지 않았다. ADL은 Barthel/한국판 K-MBI와 연결 가능한 *데이터 분류의 참고*이지, 이 엔진이 그 도구를 실시/계산하는 것은 아니다.
- 일반적인 진료 안내는 다른 분야보다 점수가 낮을 수 있지만, **점수 0도 의료 안전 보증이 아니다.** 항목 누락을 0으로 치환하지 않는다.

## 2. 데이터 최소셋: 6영역 × 5개 = 30개 질문(필수 18개)

모든 입력은 선택형 문항으로 제공하고, **미확인, 상충**을 모든 항목에 공통 선택지로 제공한다. 원문 근거/관찰일/확인자/수정이력은 향후 실사업 필수지만, 목업의 값들은 모두 허구다.

| 영역 | 필수 3항목 | 추가 2항목 | 주된 근거체계 | 환자용 가능한 출력(승인 전 공개 금지) |
|---|---|---|---|---|
| 의료 | 추적진료 계획, 퇴원직전 상태 검토, 주의상황 안내 | 미결과 검사, 동반질환 추적 조정 | AHRQ RED, 국내 퇴원연계 절차 | 외래일정, 연락처, 주의상황 |
| 간호 | 자가간호 수행, 드레싱/상처관리, 교육 이해 확인 | 기구/처치, 자가 증상관찰 | RHDS 퇴원준비도, AHRQ RED | 승인된 상처·자가관리 교육과 PDF |
| 약료 | 퇴원약 대조, 약물 변경·복약 교육, 복약관리 도움 | 약 수령, 약물 변경 문서화 | AHRQ MATCH | 약물 안내(처방/변경 생성 금지) |
| 기능 | 이동·보행, 침대/의자 이동, ADL | IADL, 보조기 사용방법 교육 | Barthel Index/K-MBI 등 연구 | 활동·보행안내/지원수단 |
| 사회환경 | 지원가능 인력, 주거 이동환경, 통원 이동수단 | 동거/지원상태, 비용·접근 제약 | 퇴원기 사회지원 연구, 통합돌봄 취지 | 돌봄 지원 검토·서비스 이용 도움 |
| 연속성 | 추적진료 예약, 문의처, 최종 퇴원안내 | 지역기관 의뢰 상태, 공적 신청동의 | AHRQ RED, 국내 CTM 연구, 국내 통합돌봄 업무 | 일정·연락처·진행상태 |

### 출처와 '우리 규칙'의 경계

- 국내 제도/병원협회 공지: 2026.1 퇴원환자 선별·평가와 지자체 협력 절차의 존재, **정부가 우리 자체 6영역 또는 0~3 규칙을 정한 것은 아님**. https://www.kha.or.kr/kha_home/notice_list.do?articleNo=46168&mode=view
- 보건복지부 지역사회 통합돌봄: 복합적 일상생활 지원과 신청→조사·계획→서비스 제공 주체를 구분. https://www.mohw.go.kr/menu.es?mid=a60100000000
- AHRQ RED: 약, 진료·검사 후속관리, 문제 발생시 연락·이해도 검토, 계획 전달을 강조. https://www.ahrq.gov/patient-safety/settings/hospital/red/toolkit/redtool1.html
- AHRQ MATCH: 입원 전약/퇴원약 간 불일치의 조정. https://www.ahrq.gov/patient-safety/settings/hospital/match/intro.html
- Barthel Index, 고령 재활 신뢰도·타당도 검토(네덜란드 재활 환자 대상): https://pubmed.ncbi.nlm.nih.gov/30448338/
- 한국 K-MBI 대 FIM 변환 검토(성인 재활환자): https://pubmed.ncbi.nlm.nih.gov/27930889/
- 퇴원준비도와 가정 내 대응 어려움 관련 관찰연구: https://pubmed.ncbi.nlm.nih.gov/17213738/
- 한국 퇴원전환 경험 CTM/B-PREPARED 계량 연구: https://pubmed.ncbi.nlm.nih.gov/31016320/
- 환자 사회지원 관련 면담/퇴원준비도 자료 연구: https://pubmed.ncbi.nlm.nih.gov/30287147/

**근거 등급:** 공식 문서/척도는 *입력영역 필요성*의 근거(A/B); 현재 각 선택지에 매긴 0·1·2·3 및 사회영역 복합 3등급 조건은 제품 자체 시연 규칙(C)이며 정확도·타당도 근거가 없음. 측정도구 저작권·한국어판 사용조건은 실제 임상척도 구현 전에 검토 필요.

## 3. 규칙 엔진 동작 계약

- 각 분야 **필수 3개** 중 1개라도 자료 누락이면 영역 평가 `UNKNOWN`, 상충이면 `CONFLICTING`; 값 0이나 '낮음'으로 대체하지 않는다.
- 데이터가 충분할 때만 각 필드에 부여한 시연 우선도 중 **최댓값**을 분야 등급으로 표시. 해당 항목의 규칙 ID·관찰값·선택지를 공개한다.
- `0=현재 자료에서 추가 지원 필요가 확인되지 않음`, `1=일반 안내 검토`, `2=추가 지원 검토`, `3=퇴원 전 우선 검토`.
- 사회환경은 **지원자 없음+주거 이동 장벽+통원 수단 부재**가 함께 확인된 가상 예시에서 3등급. **독거 또는 소득만으로 의료 고위험으로 분류하지 않는다.**
- 누락된 필수정보와 확인된 높은 우선도 신호가 공존하면 **평가 보류 + 잠정 근거 표시**, 낮은 등급으로 만들지 않는다.
- **종합점수·가중치·예측확률 산출 없음**. 안전 에스컬레이션/응급 판정은 검증 없이 자동화하지 않음.
- 각 규칙은 `도메인.필드.선택값` 형태의 추적 ID로 표현. 현재 원천자료 ID·날짜·검토자 연결은 다음 설계 과제.
- 선택지·규칙 변경시 `ruleVersion`과 입력 스냅샷/결과/검토이력을 함께 보존하는 구조로 발전.

## 4. 첫 환자군의 특수사항: 고령 근골격계 퇴원

- 보행보조기 사용 여부, 이동 시 타인 도움 필요, ADL/IADL, 주거 계단·화장실 접근, 통원 수단, 보호자 가용성 등은 **퇴원 후 행동계획에 직접 필요한 정보**라 우선 제안한다.
- 실제 의료지시는 수술/치료 종류별로 크게 달라짐. **체중부하 허용범위, 금기 활동, 상처 소독/약물 지시 등은 자체 평가결과에서 자동 생성하지 않는다.** 초기 가상 사례에서는 원문 요약/확인 필요 상태만 둔다.
- 실제 수술 사례로 연구/시연 확대 전에는 질환·수술 유형(고관절골절 vs 슬관절 등), 급성/재활 시점, 가정 복귀 여부, 담당 의료진 검토가능성을 결정해야 한다.

## 5. A2 목업 UI 계약

- 업무 헤더: 가상 환자 선택, 입원/퇴원(시연) 식별자, 전체 필수 항목 확인, 판단 보류·우선 검토 건수.
- 좌: 6영역 및 평가 상태, 중간: 필수/추가 입력, 우: 판단 사유·규칙 ID·문헌 출처.
- **A1:** 가상 환자 선택 모달만 구현. 실제 병원 환자목록/검색/필터는 미구현.
- **A2:** 총 30개 입력 변경 시 즉시 재평가. **저장/환자차트 반영 없음**.
- **A3:** 미발행 '검토 행동 후보'만 팝업으로 표시. 의료진 승인·환자 공개·PDF 업데이트는 의도적으로 미구현.
- 모바일에서도 화면을 볼 수 있지만 A2의 중심 사용 환경은 PC 업무환경.
- 색감: 환자용 v1.2의 저채도 의료형 녹색을 계승. 환자용 *두 패널* 색상 통일은 별도 시안에서 적용할 공통 토큰 `#edf4ef`, `#d7e5dc`, `#326d58`로 제안, **원본 앱 미수정**.

## 6. Codex 통합 개발 전 미확정 항목

1. 한국 통합돌봄 **2026년 7월 이후 최신 매뉴얼 전체 서식**의 병원용 필드/시스템 연결 확인. 이전 1월 자료를 현행 최종본으로 단정 금지.
2. 고령 근골격계 질환 하나(고관절 골절, 슬관절 치환술 등) 선택하고 전문간호/정형외과/약사 검토.
3. ADL/IADL 원척도 항목·평가방법·표준화·저작권/이용조건·한국 실무도구 검토.
4. 각 평가항목의 **환자 진술/보호자 확인/임상 관찰/처방 원문 우선순위**와 관찰일·검토권한 결정.
5. 영역별 판정기준 타당화(전문가 내용타당도, 현장 inter-rater 검증), 의료기기 해당여부 검토.
6. 미확정 정보가 있을 때 A3 승인·발행이 가능한 최소 안전 조건을 도메인별로 별도 결정.
7. 연계기관의 실제 승인·회신·수정권한 및 정보공유 동의 흐름 검토.

## 7. 현재 실제 검증 범위

- 순수 규칙 엔진 Node 5개 자동 테스트: 같은 입력 결정성, 완전자료 0등급, 누락 미평가, 상충 보류, 독거 과잉판정 금지.
- Chromium 1440/1024/390/320px: 화면 이동/입력 수정/결과 갱신/초안 모달/환자교체/초기화/스크립트 오류/가로넘침 확인(HTML 주입 환경).
- **HTTP 로컬 서버의 실제 웹주소 탐색은 테스트 도구에 의해 차단돼 수행하지 못함.** 자체 서버 응답은 확인했으나 이를 브라우저 실제 origin 동작검증과 동일시하지 않음.
- 전문 의료인 임상 적정성, 접근권한/서버 저장, Firebase, 실제 환자, 최신 정책 서식 대응은 모두 미검증.
