# 케어브릿지랩 의료진 UX 2.0 v0.4

독립 병원용 인터페이스 시안. 이전 기능은 원본 평가 엔진·저장 기록을 변경하지 않고 **읽기 전용**으로 반영한다.

## 사용법

`index.html` 하나를 내려받아 크롬·엣지에서 열면 된다. CSS·JS와 합성 사례가 포함된 단일 HTML이다.

- **화면 간 전환:** 약 340ms의 정적인 페이드. 위아래 이동 효과는 사용하지 않는다.
- **화면 내부:** A2 영역 전환, A3 안내 항목 탭, 패널/보기 토글에는 화면 전체 애니메이션을 적용하지 않는다.
- **계획 편집:** `나란히 보기 / 편집 집중`을 **환자 안내 내용 패널 오른쪽 위**에 배치.
- **A3 연동:** 기존 A3 저장 기록에서 현재 초안 상태, 평가 인계 필요 여부, 미해결 검토 기록, 문서 수, 현재 발행본·발행 이력 수를 읽어 요약한다. **원본 A3의 최종 승인 가능 조건을 재판정하지 않는다.**
- **기존 기능으로 이동:** A2 평가·저장·인계, A3 검토·승인·발행은 별도 브라우저 탭의 기존 배포 화면에서 진행한다. 이 시안의 임시 입력값은 이월되지 않는다.

## 저장 경계

오프라인 `file://`은 원본 합성 사례만 표시한다. 기존 배포 사이트와 **같은 브라우저 출처**에서 제공하는 경우에만 기존 `care-transition-integrated-v10-a3-synthetic-only` 기록을 읽기 전용으로 표시한다. 저장 실패·손상 시 원본 사례로 대체 표시한다. 기존 키에 쓰지 않는다.

의료진 승인·발행, 문서 파일 바이트, 환자 앱 B 공개 조건, 발행 버전과 철회는 원본 시스템에서만 처리한다. 조회할 수 있는 이력은 **참고 정보**이며, 이 시안은 발행 여부나 임상 적합성을 판정하지 않는다.

## 검증

`.github/workflows/hospital-ux2-v04-qa.yml`의 Playwright에서 1440×900 / 768×1024 / 390×844 / 320×760 화면을 확인한다. 화면 간 전환 vs 내부 탭 동작, 버튼 위치, 검색 커서 보존, 임시 입력, 편집 레이아웃, A3 기록 조회, 기존 저장 데이터 무변경을 검사한다.

실제 의료진 사용성, 물리 기기, 실제 인증·EMR·진료 지시·서버 트랜잭션은 검증하거나 구현하지 않았다. `main` 및 `gh-pages` 미변경.
