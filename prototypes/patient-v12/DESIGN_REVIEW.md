# UX v1.2 수정/위험/회귀 기록

2026-10-20, v1.1 기반 독립 패치. 현재 환자 중심 BM/디자인 검토용 가상 앱이며, 실제 의료기관과 관련 없음.

## 수정 전 발견
1. 글자 크게는 소수 selector에만 적용되어 일정·도움·내 정보·전체 계획 등 화면에 일관되게 적용되지 않았다.
2. 코드 입력 뒤 가상 환자를 한 번 더 선택해야 홈에 진입하는 구조였으며 사용자 기대(한 번 클릭하고 입장)와 다르다.
3. 주소·연락처 수정과 확인 팝업은 기존에도 있었으나 sessionStorage의 제한적 저장이었고, **모의 전송 요청 결과는 새로고침하면 사라졌다**. 서버로 보내는 기능은 존재하지 않았다.

## 수정 후 계약
- 체험 코드 검증 즉시 가상 홈 진입. 실패 시 같은 화면에서 안내.
- 전체 페이지/컴포넌트의 CSS 폰트값을 `--font-scale`에 연동. 웹 브라우저 저장소에 글자 크기 취향 기억.
- `demoRepository`를 단일 로컬 저장 진입점으로 사용. 주소·연락처 / 리비전 / 마지막 모의 요청 구조화.
- 브라우저 저장 실패 시 경고, 수정이 없는 저장에서 리비전 증가 금지, 변경 후 기존 요청 상태 초기화, 동일 저장본의 중복 시연 요청 버튼 잠금.
- 의료진 시연은 별도 preview.html, 환자 화면은 index.html. 실제 권한 기능이 아니며 실제 개인정보 금지.

## 자동 검증 수행
- 320, 360, 390, 768, 1024, 1440px 기본 레이아웃 탐색/로그인/주요 탭 가로넘침 및 JavaScript 오류 검사: **PASS**.
- 큰 글씨 390px 7개 화면 계산된 font-size 기본 대비 확대 확인: **PASS**.
- 큰 글씨 상태의 320/360/390/768/1024/1440px 7개 화면 리플로우/가로넘침: **PASS**.
- 가상 잘못된 코드 오류·올바른 코드 1회 입장: **PASS**.
- 주소·연락처 수정/저장 팝업/저장 모델/새로고침 후 복원: **PASS**(가상 localStorage 모의).
- 모의 전송 동의 검사/요청기록/새로고침 복원/후속 수정으로 요청 무효화: **PASS**(가상 localStorage 모의).
- 상세/PDF/이해확인/검색/의료진 발행·철회/초기화: **PASS**.

## 중요한 한계
- 이 테스트 컨테이너의 브라우저는 `file://` 및 `http://127.0.0.1`/외부 origin `goto`를 관리정책상 차단하므로 직접 탐색 네트워크/실제 origin 접근을 테스트하지 못했다. 대신 실제 인라인 HTML과 DOM을 Chromium `set_content`로 실행했으며, 저장소 복원은 deterministic localStorage mock을 주입해 검증했다. **실제 사용자 환경의 지속 저장·PDF 다운로드 동작 및 실기기 동작은 미검증**.
- 환자 코드 공개·로컬 저장·모의 요청은 실제 의료정보/기관 통신에 절대 사용할 수 없다.
- 실제 휴대폰·고령 사용자·스크린리더·임상·법률·보안 평가는 아직 없음.
