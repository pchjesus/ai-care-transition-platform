# 케어브릿지랩 의료진 UX 2.0 v0.3

독립된 병원용 UI 시안. 기존 `main`, `gh-pages`, 환자용 B, 기존 A2/A3 코드와 저장 데이터를 변경하지 않는다.

## 실행

`index.html` 하나를 크롬·엣지에서 열면 된다. HTML 내부에 CSS·JavaScript·원본 합성 사례와 A2 평가 규칙을 포함했다. 외부 파일·네트워크 호출·인증이 필요 없다.

## 주요 변화

- 흰색 기반 의료진 화면 및 목적/업무 중심 내비게이션
- 환자 목록 **기본/압축 보기**와 안정적인 검색 입력·한글 조합
- **원본 A2 v0.5의 6영역·30항목 및 평가 알고리즘**을 읽기 전용으로 표시
- **임시 입력 체험**에서 같은 규칙으로 결과를 계산하되 저장·인계하지 않음
- A2 결과 패널 접기/펼치기, A3 편집 집중/나란히 보기
- 약 140–190ms의 절제된 전환과 `prefers-reduced-motion` 대응

## 데이터 출처 및 안전 경계

- 원본 코드 기준: `main f7d011300cfcd8c5d605e5c51dad36b903bdb9ac`.
- 파일로 열면 **원본 A2 코드로 생성한 기본 합성 사례**를 보여준다.
- 기존 병원 페이지와 **같은 origin**에서 제공될 때만 `care-transition-integrated-v10-a3-synthetic-only` 저장 기록을 읽기 전용으로 표시할 수 있다. 다른 origin 및 로컬 파일에서는 기존 웹앱의 브라우저 저장값을 공유할 수 없다.
- 비정상적인 기록은 읽기 실패로 처리하고 기본 합성 사례를 표시한다.
- 평가 결과의 숫자는 **업무 검토 우선도**이며 임상 위험도·퇴원 적합성 판단이 아니다.
- A2 입력/계획 편집은 임시 UI 상태. A3 승인·발행·개정·철회, 환자 B 연결, 정식 인증·서버 저장은 **아직 통합하지 않았다**.
