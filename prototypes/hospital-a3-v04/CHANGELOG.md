# v0.4 후보 (2026-10-21)

- A3 v0.3 원본은 별도 경로와 최초 커밋으로 보존하고 개선 후보를 분리.
- 평가 이슈 누락/유효하지 않은 원자료 옵션으로 인한 승인 우회 방지, 개정 이슈 보존.
- 원천자료 검증의 누락 대상 예외 및 알 수 없는 대상 종류 허용 수정.
- PDF 해시 계산 중 환자/일반·실습/역할 전환으로 잘못된 기록에 첨부되는 문제 방지.
- 동일 PDF의 실제 SHA-256 확인 후 승인된 첨부 복원.
- 손상된 로컬 저장값 덮어쓰기·다른 환자 기록 표시·다른 탭 저장 유실 방지.
- 실습 종료 시 환자 선택 유실, 이전 환자 인쇄 DOM 잔류 수정.
- 실제 HTTP/저장/키보드/PDF/버전 회귀 및 시각 비교 검증 추가.
