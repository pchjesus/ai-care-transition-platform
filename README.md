# AI 기반 퇴원·지역사회 통합돌봄 전환관리 플랫폼

## 프로젝트 소개

국내 의료기관의 퇴원환자를 대상으로 AI 기반 위험·돌봄 필요도 평가, 의료진 검토, 지역사회 서비스 연계 및 성과 관리를 지원하는 B2B2C 헬스케어 플랫폼입니다.

## 현재 단계

간호 창업 과제를 위한 초기 사업기획 단계입니다. 실제 의료기관과 공식적으로 제휴하거나 임상적 성능을 검증한 제품이 아닙니다.
