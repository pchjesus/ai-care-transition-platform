## 변경 내용

환자용 v1.2에서 글자 확대 시 입력/검색 결과가 유실되고, 저장 실패 후에도 변경이 확정된 것처럼 표시되며, 새로고침/다른 탭에서 계획 철회가 유지되지 않는 문제를 수정합니다. PDF 생성 오류·자원 정리·모달 초점 복귀도 보강했습니다.

v1.2 원본은 `prototypes/patient-v12/`에 해시와 함께 보존하고, v1.3은 `prototypes/patient-v13/`에서 별도로 관리합니다. 데이터/저장소/PDF만 분리했으며 CSS와 기본 UI·문구는 유지했습니다. 기존 profile/request/font를 원본 키 수정 없이 마이그레이션합니다. 병원용 A1/A2/A3 변경·실제 인증/EMR/Firebase·배포는 포함하지 않습니다.

## 검증

- Node 저장/PDF 12/12, 실제 HTTP 회귀는 원본 모듈·생성 HTML 각각 20/20 PASS.
- 기존 assertion을 모듈 HTTP·생성 HTML HTTP·주입형 standalone에서 모두 실행해 PASS.
- 5개 폭 × 11개 화면 55쌍 픽셀 동일. 오류 경로의 의도적 변경은 전후 캡처로 기록했습니다.
- v1.2 원본·CSS·PDF 바이트 보존, 마이그레이션/손상/저장 실패/탭 충돌/실제 다운로드/계획 버전·철회/키보드 검사 PASS.
- file:// 직접 실행은 브라우저 정책으로 NOT RUN이며 성공으로 보고하지 않습니다.

상세 재현·로그·전후 화면·잔여 제한은 `docs/patient-v1.3/REPORT.md`에 있습니다. 합성 데이터용 로컬 시연이며 실제 임상 성능·인증·기관 전송을 검증한 제품이 아닙니다. Draft 검토만 요청하며 병합하지 않습니다.
