# 2026-10-22 — 환자 B 사용성 회귀 수정 / 독립 시연 복구 / 구조화 일정

## 발견
- 연결 B의 도움 카드가 원본 CSS의 `service-card-text` 대신 존재하지 않는 `service-copy` 클래스를 사용하여 제목/설명이 줄바꿈 없이 붙어서 표시됨.
- 기존 독립 환자용 B v1.3이 삭제된 것은 아니나 홈페이지와 연결 화면에서 덜 눈에 띄어 빠르게 둘러볼 방법이 부족했음.
- 외래 날짜/장소는 A2의 추적 상태만 있고 A3에서는 자유 서술 안내문만 편집 가능하여 날짜를 구조화해 B 일정으로 표시할 수 없었음.

## 변경
1. 연결 B 카드의 실제 CSS 클래스를 원본과 일치시키고, 제목/설명 세로 스택 및 긴 한국어 줄바꿈을 명시. 좁은 화면·큰 글자에서 카드 폭 및 일정 카드 배치를 보조. 독립 B 원본 CSS와 기능은 보존.
2. 기존 독립 환자용 B 바로가기를 통합 홈 **최상단 빠른 체험**과 연결 B 로그인·상단에 다시 노출. 승인 전 예시와 A3 공식 발행본을 혼동하지 않도록 시연 모드 구분.
3. A3 환자계획의 `followup`에만 선택형 `appointment:{status,date,time,place}`를 제공. 기존 저장 레코드에는 강제 추가하지 않음. PENDING과 완성되지 않은 CONFIRMED를 구분하며, CONFIRMED는 날짜·시간·장소 및 유효한 캘린더 날짜가 있어야 승인이 가능.
4. A3 편집은 승인·검토 무효화/자료 재확인/저장 실패 롤백 기존 계약을 따름. 승인·발행된 환자 스냅샷에만 CONFIRMED 날짜·시간·장소를 제한적으로 전달. 환자 B의 일정 화면에서는 이 정보만 구조화된 예약 예시로 노출. 날짜가 없거나 PENDING이면 `일정 확인 필요`로 표기하고 예약을 추정하지 않음.
5. 기존 발행본 스냅샷·해시·저장 버전 호환. 기존 발표 기록과 독립 환자용 B는 변경하지 않음. 실제 예약/EMR/의료진 인증/기관전송 구현 아님.
