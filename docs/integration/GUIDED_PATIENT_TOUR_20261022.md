# 합성 환자 이름 복원 및 학습 탭 가이드 체험 — 2026-10-22

## 배경
환자용 연결 화면의 `SYN-001 · 합성 환자 안내` 표시가 과거 독립 B v1.3의 친근한 이름 안내보다 기계적으로 보인다는 피드백. 학습 탭의 기존 `쉬운 실습 시작`은 바로 실제 병원용 화면으로 이동해 초심자에게 급격한 전환이 발생했다.

## 설계 및 구현
- 환자용 B에 이름을 표시하되 **검증된 A3 발행본의 patientId·encounterId와 합성 사례 레지스트리 `CASES`가 일치할 때만** `이정희님` 등의 합성 이름을 화면 제목에 표시한다. 임의 환자 로컬스토리지나 URL에 포함된 이름을 신뢰하지 않는다.
- 병원용 A3 학습 탭의 L01과 L04에 `화면 따라 체험하기` 버튼을 추가한다. `showModal()`로 다른 화면을 흐리게 한 별도 학습창에서 A1→A2→A3 작성→승인/발행→B 오늘→B 일정 순서 6단계 안내, 강조 표시·화살표·진행률·이전/다음/건너뛰기·ESC 닫기 기능 제공.
- 튜토리얼 단계는 **실제 업무 화면이 아닌 합성 화면 미니어처**를 보여준다. 안내창 자체는 `get()/save()`나 일반/실습 저장소를 호출하지 않는다. 마지막 단계의 링크만 기존 독립 B **v1.3**을 새 탭에서 열어 진짜 화면을 직접 사용하게 한다.
- 기존 `data-study-start` 케이스 실습은 별도 버튼으로 보존해 현재 합성 A3 사본 실습 흐름이 변하지 않는다.
- 기존 독립 B와 공개 발행 스냅샷·다영역 평가·승인 게이트는 변경하지 않는다.

## 검증 계약
- PASS 여부는 실제 실행한 JS 구문·직접 함수 테스트로만 기록한다.
- 단위 테스트 추가: `a3/tests/tutorial-tour.test.js`, `shared/publication.test.js`(환자 이름과 입원건 불일치).
- Node 전체 스위트/Chromium E2E/모바일·접근성 검증은 별도 Codex에서 실제 실행하기 전까지 NOT RUN.
- 공개 웹사이트에 변경을 반영한 경우 실제 사용자의 클릭 시연은 별도로 검증해야 한다.
