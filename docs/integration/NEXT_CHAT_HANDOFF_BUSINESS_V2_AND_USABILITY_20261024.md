## 2. 다음 채팅의 **첫 번째 작업 — 사업성 근거 강화 (우선)**

추가 구현/문서 개정 전에 아래 사업 질문을 순서대로 다룬다.

1. **병원이 구매할 이유:** 현행 퇴원교육·연계업무 흐름과 반복 설명·누락·추적의 문제 가설, 측정 가능한 편익(담당자 시간, 처리 건수, 재안내 요청, 행정 관리 부담). 예시 계산은 반드시 가정값으로 표시. 임상효과·재입원 감소 주장 금지.
2. **구매자/가격/계약:** 실제 사용 부서와 구매 결재·IT 보안·법무 담당자 분리, 도입 일정, 초기 설정, 교육비, 유지비, 병원별 과금 단위와 병원 확장형의 지불의사 시험안.
3. **경쟁·대체제 차별성:** 나의건강기록, EMR 내부 퇴원교육, 공공 통합돌봄·의뢰체계, 간병/생활지원 플랫폼, 글로벌 퇴원·사회서비스 솔루션 중 실제 직접 대안만 선택해 현재 기능·공식 제공 범위를 비교. 검증 안 된 경쟁사 기능 부재를 단정하지 않는다.
4. **영업·진입전략:** 첫 사용 부서 → 의료진 챔피언 → 보안/구매 결정권자 → 합성 시범 → 적법한 파일럿/정식 계약. 병원 직접 영업 vs 기존 병원 IT 공급사/구축사 채널의 고객획득비·책임 배분 가설 비교.
5. **AI 로드맵:** 현재 A2 규칙 기반 업무 평가를 미래의 임상의사결정지원 AI로 과장하지 않는다. 단계별 가설: 문서 요약·확인사항 누락 알림 → 의료진 검토 효율 보조 → 근거 확보 후 연계 후보 탐색 지원. 평가/승인/환자공개의 계층 분리.
6. **흑자 전환·민감도:** `v2.0`에 기준(-1,680만원), 조건부 6병원(+680만원), 8병원 성장(+2,310만원)의 2029년 매출·비용 상세표 존재. 그 수치는 시나리오. 병원 가격 50/75/80만, 도입비 200/400만, 프리미엄/업체 SW, 영업·보안비·고정비 가정의 현실성과 손익분기점·CAC·유지율·추가 인건비에 따른 민감도 분석. **없는 계약·제휴·매출을 사실로 쓰지 않는다.** 독립 SW 사용료와 규제될 수 있는 환자 소개 수수료를 구분.
7. 현행 사용자용 무료 핵심 안내는 유지하면서 이동·보조기구·돌봄을 향후 **실제 정보/연계/신청으로 확장하는 공격적 비전**을 제시한다. 단 상용 호출·결제·공적 자격 결정이나 제휴를 이미 완료했다고 표현하지 않는다.

출력: (A) 확인된 사실/증거, (B) 구매 및 차별화 가설, (C) 가격·손익 재계산/민감도, (D) 사업계획서 개정안과 15장 발표자료 재배치안을 **먼저 채팅에서 정리**한 뒤, 검토된 결정사항으로 원본 DOCX/PPTX를 v2.1로 수정·PDF 내보내기·렌더링 확인. 차별성은 발표 8장, 확장 10장, 수익 11~12장, 로드맵 13장, 비전 15장 등 중심. 기존 5+12 과제 서식은 유지. 사용자가 승인 전인 핵심 사업 가정은 독단적으로 확정하지 않는다.
