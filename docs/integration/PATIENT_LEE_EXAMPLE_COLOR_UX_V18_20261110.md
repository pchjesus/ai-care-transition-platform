# 케어브릿지랩 환자 앱 — 이정희님 합성 예시 기반 UX v1.8 비교 시안

**기준일:** 2026-11-10 · **상태:** 독립 합성 예시 UX 후보 / 사용자 디자인 승인 전

## 왜 이정희님으로 다시 만들었나

이전 v1.6/v1.7 후보는 A3 연동형 B에서 미발행 시 빈 화면을 보여주므로, 의료진 작업 없이 디자인 전후를 쉽게 비교할 수 없었다. 기존 독립 환자 예시 `patient/index.html`에는 **1950년생 가상 환자 '이정희'**, 퇴원 예시 내용 3종(보행 보조기 안내, 퇴원 약 안내, 다음 진료 준비), 2026-10-27 과거 외래 사례, 가상 PDF, 도움찾기·알림·프로필·선택형 이해 확인 문제가 이미 있다.

따라서 이번은 **새 합성 질환/처방을 만들지 않고 동일 fixture로 시각·행동을 비교**한다.

## 파일과 체험

- **원본:** `patient/index.html` (그대로 보존)
- **새 디자인 후보:** `patient/v18.html` + `v18.css` + `v18-controls.js`
- **원본/새 디자인 비교:** `patient/compare-v18.html` — PC 나란히, 모바일 원본/새 디자인 버튼 전환
- **통합 홈 색상 연계 후보:** `prototypes/integrated-v10/v18-home-preview.html`
- **임시 시연 코드:** `CARE2026` (**보안/본인 인증이 아님**).
- 전체 미리보기는 동일 출처 HTTP(S)에서 열어야 외부 ESM·모듈이 정상 동작한다. GitHub raw는 실행 페이지가 아닌 원문이다.

## 시각 방향 — Calm Ocean & Apricot

- 의료진 업무화면의 화이트/블루 확정 디자인과 *동일한 화면*을 강요하지 않는다.
- 환자 앱은 **부드러운 오션 블루/아이보리 화이트 + 연한 살구색**으로 구분하되, 정보는 고대비 잉크 네이비와 충분한 줄 간격을 사용한다.
- 첫 화면: 환자 인사/시연 상태 → **보행·퇴원 약·진료 준비 3개 안내 CTA** → 일정 확인 → PDF·도움받기 → 짧은 사용 설명.
- 5개 하단 목적지(오늘/일정/도움/알림/내 정보)를 모바일에서 **전부 보이게** 배치, 선택 상태는 배경·윤곽·텍스트 모두에서 구분.
- 글씨 크기 2단 세그먼트와 모션 감소 스위치를 접근 가능한 모달/모바일 바텀시트로 제공.
- 움직임은 180~230ms 내외의 짧은 fade/press 피드백만. 의료지시 본문 지연/자동 넘김/긴 모션 없음.
- 2026-10-27 예시 일정은 2026-11-10 현재 과거이므로 **'다음 예약'으로 오인시키지 않고 과거 합성 일정으로 명시**.
- 통합 홈에서는 **환자 카드 아이콘을 살구색, CTA를 오션 블루**로 연결하되, 운영 홈은 그대로 유지.

## 보존 계약

- 원본 `patient/index.html`을 건드리지 않는다.
- 독립 예시의 **가상 자료만** 사용. 실제 A3 승인·발행본 또는 의료기관 기록과 연결된 척 하지 않는다.
- 독립 예시의 PDF, 이해 확인, 일정, 도움 검색, 알림, 프로필 수정·로컬 저장, 모의 전송·철회 상태 기능을 유지한다.
- 새 모션 설정은 별도 `carebridge-demo-b-v18-less-motion` 로컬 키만 사용. 원래 환자 저장·문서 계약과 별도다.
- 공유 publication·storage·A2/A3 엔진, v1.7 통합형 후보, 운영 `main`/`gh-pages`는 변경하지 않는다.
- **최종 디자인이 선택되면 A3 연동형 B에 이 색상과 조작을 포팅하고 원본 안전 규칙을 다시 통합 검증**해야 한다. 이 디자인 시연을 A3→B 전체 통합 완료로 보고하지 않는다.
