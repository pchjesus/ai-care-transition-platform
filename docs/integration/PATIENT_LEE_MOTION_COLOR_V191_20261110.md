## 문제와 조치

### 1. 화면 내부에서 불필요한 위아래 모션 발생

**원인:** v1.9 CSS는 `main > .profile-layout`, `main > .service-page` 등 새 DOM이 생길 때마다 `v19-route-in` 애니메이션을 실행한다. 화면 내부 토글/프로필 수정 등에서도 전체 내용이 매번 재생성되는 구조라 탭 이동처럼 튀었다.

**조치:** 기존 뷰 전환 로직을 보존하고 `v191NavMotionPending` 일회성 플래그를 도입했다. `.side .side-nav[data-nav]` 또는 `.bottom-nav button[data-nav]`에서 **실제 다른 상위 메뉴(오늘·일정·도움·알림·내 정보)**로 이동할 때만 생성되는 `main.v191-top-level-motion`에 진입 모션을 건다.

- 상위 탭 전환: **390ms**, 7px 이내 아래→제자리, opacity .76→1, `cubic-bezier(.22,1,.36,1)`.
- 탭 안쪽: 도움 검색 열기, 프로필 편집/확인, 모달·택시 선택, 안내문·퀴즈·알림 변경, 글자 크기 변경에서는 화면 전체 애니메이션 **없음**.
- 버튼·토글은 의미 있는 배경색·테두리·텍스트 선택 피드백만 175ms 내외로 남긴다. 스위치의 엄지 위치 전환은 조작 상태로서 짧게 유지.
- 운영체제 `prefers-reduced-motion` 또는 기존 환자 설정 `움직임 줄이기`를 켜면 **상위 메뉴 모션도 제외**.

### 2. 스크린샷에 보이는 기존 초록색 잔존

- `.transfer-status`(정보 업데이트 요청): 연한 오션 블루 안내 박스와 **살구색 왼쪽 강조선**, 진한 블루 글씨.
- 주소/연락처 수정·기관 모의 요청 버튼: 활성은 오션 블루, 비활성은 읽기 쉬운 회청색으로 구분. 실제 기관 전송 불가 상태 유지.
- 기존 `.secondary-action:hover`, `.home-help-shortcuts button:hover`, `.service-card:hover` 등 초록색 호버 및 설명문·프로필 태그·도움 검색·PDF·동의창·알림 및 보조 CTA 색상을 블루 계열로 통일.
- 정보 성격에 따른 6:3:1 적용 지향: **약 60% 무채색 여백·카드**, **30% 블루 안내·조작**, **10% 이내 살구색 주의·차별화**. 실제 픽셀 비율은 측정하지 않았으며 일종의 시각 위계 원칙이다. 새로운 세 번째 브랜드색은 추가하지 않았다.
- 오류·발행·철회·기관 전송 미구현 등 **의미상 중요한 상태는 장식 색상 때문에 완료/성공으로 바꾸지 않는다.**
