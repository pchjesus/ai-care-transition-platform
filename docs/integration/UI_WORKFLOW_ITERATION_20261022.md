# 2026-10-22 A2/A3/B 사용성 피드백 패치

## 범위·근거
사용자 스크린샷: 왼쪽 병원 메뉴에서 A1/A2/A3/B 약한 대비. A2 가로 6개 영역 선택이 세로 공간을 차지해 3패널 제안. A3의 검토 요청 이후 승인자 역할 선택이 불분명하고, 환자용 B의 미발행 빈 화면에 예시 접근이 부족. 기록 선택 대안이 충분히 드러나지 않음.

## 변경
- 통합 `a3/index.html`의 접힌/펼친 레일 버튼 글자·테두리를 더 흰색·두껍게 지정. 선택 항목은 흰색 배경과 진한 글씨.
- 통합 A2는 넓은 화면(≥1320 CSS px)에서 좌측 영역 탐색, 중앙 평가 입력, 우측 판단·근거 3패널. 좁은 폭은 원래 가로형 선택·2패널 보존.
- A3 작업 상태 아래에 시연용 역할 전환·검토 요청·승인·발행 순서 설명. 실제 권한 검증은 역할 선택과 다른 개념임을 안내하고 기존 `mayApprove / mayPublish / blockers` 유지.
- 합성 근거자료를 주제별 추가하고, 현재 항목에 연결 가능한 확인된 기록을 선택창 상단에 정렬. 다른 환자·미확인 자료의 연결은 기존 검증 그대로 거절. SYN-003 약료 상충 상태 보존.
- 실제 환자용 B 미발행·철회 차단은 그대로 유지. 빈 화면에 발행 절차와 **별도 독립 환자용 시연**, **A3 초안 미리보기(미발행 명시)** 링크만 추가. 승인된 의료정보처럼 예시 자료 자동 주입 금지.
- 기존 독립 B v1.3, A2 원본 엔진, A3 평가·발행 데이터 스키마 수정 없음.
