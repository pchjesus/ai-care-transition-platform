## 목적과 디자인 결정

- 기존 v1.8 **차분한 오션 블루 + 은은한 살구색**을 앱 전반의 단일 시각 언어로 정리한다.
- 중장노년층이 모바일에서 **무엇을 누르고, 어떤 것이 미연결 상태인지, 돌아가는 길은 어디인지** 쉽게 파악하게 한다.
- 시각적 움직임은 더 적극적으로 사용하되 콘텐츠가 튀거나 흔들리지 않도록 **180~285ms, 약한 거리(5~14px), 점진적 페이드, ease-out 곡선** 중심으로 제한한다.
- 사용자가 `움직임 줄이기`를 설정하거나 운영체제가 `prefers-reduced-motion`을 요청하면 부수 모션을 즉시 제거한다.

## 구현

1. **기존 CTA/패널 색상 정리:** 환자 하단 메뉴, 도움받기, 자료/PDF, 상세, 일정, 설정, 프로필, 알림 관리의 이전 포레스트 그린 잔여색을 오션 블루·화이트로 재통일. 버튼 호버/누름·선택 피드백을 더 자연스럽게 연결.
2. **지도 안내 개편:** 의료진이 확인하고 발행한 목적지에만 외부 지도 링크 제공. 이정희님 독립 합성 사례는 실제 주소가 없으므로 ‘지도 열 수 없음’의 원인과 주소 확인 방법을 **큰 아이콘·2단계 안내**로 표시. 거짓 지도 핀/길찾기·현 위치 전송을 생성하지 않음. 공식 주소가 확인된 실제 A3 연동형 코드의 관련 계약을 이번에는 수정하지 않음.
3. **택시·이동지원 완전 재배치:** 일반 택시와 이동지원 확인을 **선택형 카드 2개**로 구분; 차량·이동지원 적합성은 외부 확인. 출발지 → 필요한 보조기구·동행·하차 도움 → 확인의 **명시적 3단계 진행 표시**. 입력은 일시적 미리보기이며 실제 호출, 예약, 요금, 결제, 병원 전송 등은 사용 불가 상태로 정직하게 표시. 승하차·동행과 보조기구를 선택해도 저장소·기관으로 보내지 않음.
4. **모바일 바텀시트:** 기존 중앙 대화창 대신 화면 아래에서 등장하는 정돈된 시트(PC는 적당한 너비의 대화창). 헤더 닫기·상태·단계 버튼을 항상 직관적으로 구분. 날짜/문서/지도 관련 화면에서 합성 데이터·실제 호출 여부를 명확히 표시.
5. **애니메이션·모션 감소:** 화면 진입/탭·카드 반응, 이동 패널과 대화창의 부드러운 단계별 전환. 지시문 글자 뒤섞기, 자동 넘김, 클릭 불가능한 장식 CTA는 도입하지 않음.
6. **기존 기능 보존:** 이정희님 기존 3개 안내, 가상 2026-10-27 외래, 원본 독립 PDF, 선택형 이해 확인 문제, 도움, 알림 저장·복구, 가상 프로필 수정, 로컬 요청·발행/철회 시연, 글씨 크기 토글, 이전/다음/홈, 5탭 유지.

## 안전·검증 경계

- 실제 환자·실제 병원 주소/좌표 없음; 이정희님은 **1950년생 가상 환자**이며 공개 시연 코드 `CARE2026`은 인증 아님.
- 페이지는 **A3 발행본 연결이 없는 독립 합성 시안**이다. 승인·발행·철회의 진짜 A3→B 데이터 흐름을 이번 UI 테스트로 검증했다고 주장하지 않는다.
- 임상 위험도·복약·일정·운송 가능 여부를 AI가 계산하거나 실제 의료지시로 생성하지 않는다.
- 지도/택시/알림은 현실 세계 예약/전송 미구현을 시각적으로도 표시한다.
- 기존 공유모듈·A3 데이터 계약은 이번 변경에서 손대지 않았으며, 최종 환자 UI 선정 이후 **A3 연동형 B에 별도 이식 + 원래 발행·개정·철회 회귀검증** 필요.
- 실기기, 화면낭독기, 고령층 이용성(실제 과제 수행/오류율/이해도), 지도·택시 외부 연결·비용 검증: **NOT VERIFIED**.
