## 데이터·저장 계약

- 새 키: `carebridge-reminders-v1:{connected|independent}:{patientId}:{encounterId}`. 계획별 설정은 발행 ID·버전·평가 ID에도 묶인다. 임상 저장소와 기존 개인 프로필/이해 확인 키는 재사용하거나 마이그레이션하지 않았다.
- 개정 중에는 기존 유효 발행본을 따른다. 새 버전 발행 시 이전 설정은 비활성화하고 새 설정은 꺼짐에서 시작한다. 철회/불일치/손상 시 임상 알림을 계산하지 않는다. 과거 설정을 보존해도 화면에 다른 환자·버전의 내용을 표시하지 않는다.
- Web Locks로 같은 출처의 설정 쓰기를 직렬화하고 저장 전 원문 비교로 오래된 탭을 거부한다. 저장 거부/용량 초과/손상 시 성공을 표시하지 않고 입력값을 보존한다. 저장 중 중복 조작을 막으며 대기 중 닫기는 저장 취소를 알린다. Web Locks 미지원/비보안 실행에서는 안전하게 저장을 거부한다. 서버 트랜잭션·인증을 의미하지 않는다.
- 추가 승인 필드: 선택형 `appointment.destination`, 문서 `category`. 기존 필드가 없는 자료는 그대로 유효하고 이전 승인 해시를 바꾸지 않는다. 새 분류는 해시에 포함하며 목적지는 기존 항목 해시에 포함된다. A2 계산 엔진/6영역·30항목 규칙과 승인·발행·개정·철회 권한/순서는 변경하지 않았다.
- 현재 A3 계약은 확정 일정에 날짜·시간·장소를 모두 요구한다. 불완전한 일정은 계속 미확정으로 차단한다. 알림 계산기는 날짜만 제공될 후속 어댑터에도 지정 알림시각/시간대로 대응하며 단위 테스트했다. 현재 A3에서 날짜만으로 확정 발행했다고 주장하지 않는다.
