## 0. 왜 바꾸는가

- 이전 1차 문제: 병원 퇴원연계 담당자의 평가·서류·의뢰 업무 비효율.
- **새 1차 문제(가설): 퇴원환자·보호자가 자신의 상태, 일상 자가관리, 약, 진료, 주의증상, 도움 요청, 지역 돌봄을 이해하고 실천하기 어려움.**
- 2차 가치: 의료진이 설명·안내서를 준비하고 승인하는 부담 감소.
- 3차 확장: 공적 돌봄제도·지역기관과 안전하게 연결하되, 정부 공식 자격판정을 대신하지 않음.
- 첫 사업 형태 가설: **B2B2C**, 환자·보호자 무료 사용, 의료기관의 안내 생성·검토·배포 도구 계약. B2C 및 EMR 제휴는 비교 후보.
- **첫 검증 지표:** 환자의 올바른 다음 행동 선택·정보 찾기·이해도. 병원 업무시간·수익화는 보조 지표.
- AHRQ RED 툴킷(미국, 한국 현장 검증과 구분): https://www.ahrq.gov/patient-safety/settings/hospital/red/toolkit/redtool3.html ; https://www.ahrq.gov/patient-safety/settings/hospital/red/toolkit/redtool6.html

## 2. 실제 수행 순서 (번호순이 아님)

### Gate A — 환자 문제 확정 / 첫 MVP 범위
**R00 → R13 → R05 → R12 → R02** (R08 초기 안전검토 병행)
- 환자·보호자가 실제로 혼란스러워하는 순간 최소 3종의 JTBD를 정의한다.
- 환자와 보호자, 퇴원교육 담당자 각각 탐색 인터뷰 **모집 목표**를 정하고 실제 수행 시 기록한다. 인터뷰가 없다면 공개 근거 기반 가설이라고 표시한다.
- 첫 환자군 하나와 첫 사용환경(퇴원 직전/귀가 첫날 등)을 제안하고 검토한다.
- 대표 가상 업무 비교(현재 서면안내 vs 제품 안내)의 과업·성공 판정 기준을 정의한다.
- 기존 디지털 환자앱·안내 서비스와 진짜로 다른 부분을 확인한다.
- 생명·건강 관련 안내는 승인 근거, 누락, 충돌, 미승인 공개 방지 테스트가 있어야 한다.

### Gate B — 국내 제도와 정보 경계
**R01 → R06 → R08 상세**
- 병원 퇴원 계획 vs 지자체 승인 돌봄 계획의 소유·출처·승인/변경 권한 구분.
- 신청처·동의/보호자 권한·서비스 중단·종결/재신청 경로의 정확성.
- 첨부 2026.4 개정 HWPX는 [R01-C v0.2](./R01C_APRIL_2026_AMENDMENT_VERIFIED_v0.2.md) 참고. 4월 개정안의 주요 신구항목 검증 완료, 전체 병원실무는 미검증.

### Gate C — 사업 성립과 발표 방어
**R03 → R04 → R07 → R09 → R10 → R11 → R15 → R14**
- 환자 이해도 개선이 '환자에게 좋음'에서 '병원이 지불할 가치'로 이어지는지 **구매 논리**를 검증한다.
- 구독/퇴원관리건수/구축비를 실제 도입비·간호교육 절감·운영비와 비교한다.
- 기존 BM의 연 1,800만 원, 3년차 20개 기관 등의 수치는 *과거 고객·기능 가정의 산술 시나리오*이므로 신규 BM의 전망으로 재활용하지 않는다.

### Gate D — 실증·확장
**R16 → R17 → R18**, 설계 게이트 승인 후 개발/사업화 검증.

## 3. 요구되는 근거 층위

- **A 확인 사실:** 공공문서·공식 통계·논문 원문에서 확인한 구체적인 대상/연도/내용.
- **B 간접 근거:** 연구와 전문 가이드라인이 유사한 문제의 가능성을 보여줌. 한국 환자에게 그대로 효과 입증 X.
- **C 사업·기술 가설:** 제품 적정가격, 병원 구매전환율, 30일 사용률, 시간절감 등.
- **D 미검증:** 인터뷰/실사용 실측/실제 EMR·기관 연동/임상 성능.

모든 발표 주장은 주장 ID·원문·대상 집단·기준연도·한계·적용 여부를 기재한다.

## 5. 남은 중요한 질문

1. '정보를 보기 쉽다'뿐 아니라 **다음 행동을 정확히 실행**하게 만들 수 있나?
2. 퇴원 후 30일이 모든 질환의 알맞은 기간인가? 질환/치료단계별 선택이 필요한가?
3. 스마트폰 접근이 어렵거나 보호자가 없는 고령 환자에게 어떤 대안이 있는가? (인쇄, 설명용 큰 화면, 전화 등)
4. 계획이 바뀌면 기존 내용을 언제 누가 수정하고 환자에게 알릴 수 있는가?
5. 환자의 앱 사용 로그가 병원에 실제 업무를 발생시키거나 과도하게 감시하는 구조는 아닌가?

7. 환자 서비스가 좋아도 병원에서 계약하지 않는다면 유통·지불 구조를 어떻게 바꿀 것인가?
