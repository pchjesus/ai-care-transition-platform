## 수익화의 구별

1. **주력:** B2B/B2G 기관 사용료, 기능별 기관 라이선스, 화이트라벨, 정기 유지보수·온보딩 (모두 가격·계약 가설).
2. **편의서비스 부가:** 이용자가 직접 선택한 숙소·교통·비의료 생활서비스의 제휴/광고수익 가능성. 해당 업체의 실제 파트너 계약, 제휴 대상, 표시 의무, 환자 관련 법적 위험 별도 검증.
3. **보조기기·생활:** 의료기기는 허가·신고/급여 규칙이 다를 수 있고, 구매/임대사업·직접 추천을 단정하지 않음. 정보 제공부터 시작.
4. **높은 주의:** 환자 의료기관 유인·알선에 따른 거래 수수료, 비승인 의료지시 자동화, 처방전 제공 대가, 환자 건강정보의 상업 판매, 치료·장기요양 자격의 자동 판정 — 수익 모델에서 기본 제외 또는 전문 법률 검토 선행.

## 숙박 연계 사실 확인

- 아고다: 공식 제휴 파트너 프로그램과 demand API 안내 존재. 웹 게시 안내에는 완료된 예약 규모별 4~5% 예시가 있으나 계약·트래킹 및 지급 조건 확인 전 사업수익 확정 불가.
- 여기어때: 마케팅 파트너 안내 존재. 콘텐츠 제작자 중심이므로 일반 환자앱 사업자의 API/제휴 가능 여부는 **NOT VERIFIED**.
- 2025-07-11 청담해리슨병원과 안다즈 서울 강남의 숙박 제휴 사례가 보도됨. 이는 수요모델의 실례이지 케어브릿지랩 제휴가 아님.
- 추천 MVP: '외래 일정 준비' 내 **병원 근처 머무를 곳 찾기** 정보 카드. 방문 날짜는 사용자가 확인하고, 실제 숙박·가격·가용성은 외부 서비스에서 재확인. 실환자 의료정보·입원 사실을 호텔에 전달하지 않음.

## 우선순위 제안 (아직 결정 아님)

- **1차 시각화:** 병원 접근 경로, 택시/이동 도움, 병원 인근 숙박 검색 안내, 의료보조기기 안내, 공공지원 자격 확인 링크.
- **2차 파트너 검토:** 접근성 숙소 필터, 교통약자 차량, 지역 복지 자원, 보조기기 전문업체, 식사·청소·돌봄 생활서비스.
- **3차 장기:** B2B 기관용 지원 카탈로그/회신, 정식 숙박 제휴 계약, 통합 서비스 진입, 인증·동의·보안·서버 인프라.

환자앱은 홈에 상업 카드를 무더기로 나열하지 않고 '오늘 할 일'과 임상상 중요한 경고를 먼저 보여주며, 비의료 편의서비스는 별도의 **생활·이동** 영역에서 요청에 따라 선택. 공공·비상업 선택지와 광고/제휴 여부를 명확히 구별할 것.
