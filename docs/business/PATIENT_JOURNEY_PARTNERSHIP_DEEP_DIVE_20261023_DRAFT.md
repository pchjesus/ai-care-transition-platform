# 케어브릿지랩 — 환자 여정 연계서비스·파트너십 상세 탐색 (DRAFT v0.2)

작성일: 2026-10-23 KST. **확정 제휴·거래·임상 검증 아님**. 사용자 요청에 따른 폭넓은 시장·연계 발산안.

## 0. 상태와 분류 체계

- **공식 확인**: 특정 플랫폼이 파트너·API·급여제도·보조기기 지원체계를 공식 페이지에서 안내함. 케어브릿지랩 계약 승인은 아님.
- **검토 가능**: 공개 제휴 신청 안내는 있으나 업종·지역·신규 파트너 자격·계약 조건 미확인.
- **가설**: 구상으로만 분류. 외부 API·정산 비율·법적 허용을 단정하지 않음.
- 의료진 A1→A2→A3 승인·발행→B 흐름과 평가 규칙·환자/입원건 저장·철회는 별도 안전 계층. 이 문서는 상품 추천 엔진 구현 지시가 아님.
- 모바일 햄버거 UI 및 상단 압축은 `feature/patient-mobile-drawer-krds-20261023`에서 별도 검증. `main`/`gh-pages` 및 Codex 최종 검증은 사용자 결정 전 변경하지 않음.

## 4. 서비스 연결 단계(관찰 가능 수준)

- **L0 정보/링크**: 병원·지자체·제품·숙박 서비스에 대해 일반정보·공식 홈페이지로 이동. 외부로 데이터 미전송. 초기 추천.
- **L1 조건 입력 UI**: 일정·거리·예산·휠체어 여부·도움 필요(사용자 자발 입력/합성만)로 정리, 외부 사이트에서 재확인. '예약 진행 중' 표시 금지.
- **L2 확인된 제휴 링크**: 실제 파트너 계약과 광고/경제적 이해관계 표기, 클릭/예약 추적은 민감정보 없는 최소 식별자만, 외부 개인정보 제공 별도 동의.
- **L3 API 검색/예약**: 정식 API 권한, 서버 인증·결제·환불·오류·동시성·예약 철회·고객지원·비상연락 및 외부 동의 기록 필수.
- **L4 기관 서비스 회신**: 병원/보건소/업체별 법적 권한에 따른 이용자 동의·실제 담당자 승인·회신 통신 기록 및 재시도, 장애 복구. 현재 MVP 바깥.

## 6. 추천 타깃 상황과 묶음 서비스

1. **타지역 외래 재방문**: 진료일 확인 → 이동수단 선택 → 무장애 숙소 필터 → 보호자 체류 → 환불 조건·시간 확인.
2. **근골격계 수술 후 귀가**: 의료진 발행 보행 정보 → 워커/휠체어 장비 경로 → 차량 탑승 가능 확인 → 집 안 동선·욕실 안전 → 공공 급여·대여 경로.
3. **고령 독거 퇴원**: 지역 통합돌봄 상담 → 방문요양/식사배달 → 안부 확인 → 보호자/사회복지 담당자 재확인.
4. **보호자 동행 장기진료**: 가족 숙소/주차/식사/교대 일정 → 병원 내 길찾기/문의 → 비의료 서비스는 환자가 직접 선택.
5. **지역사회 지원 연계**: 지자체 통합돌봄 신청→조사·판정→지원계획→제공→모니터링. 플랫폼이 급여대상이나 서비스승인을 자동 판정하지 않음.

## 7. 빨간선과 안전설계

- 의료법 제27조: 영리 목적 환자 의료기관 소개·알선·유인 관련 금지. 유료 상품 제휴와 의료기관 선택을 분리. 병원진료 쿠폰·진료비 기반 추천 수수료 등은 피함.
- 의료기기법 제17조 판매·임대업 신고, 제18조 의료인·의료기관 경제적 이익 제공 제한. 의료기기 채택과 수익활동 연계는 전문 법률 확인.
- 개인정보 보호법 제23조: 건강정보 등 민감정보 처리 요건. 외부 호텔·택시·상품업체에 입원·진단·평가결과 자동 전달 금지. 환자 자발 입력과 의료정보 분리, 정보 최소화.
- 공정위 추천·보증 등 표시·광고 심사지침(2026.6.1 시행): 제휴/광고 노출 시 경제적 이해관계 투명하게 표시.
- 장기요양보험 방문간호는 방문간호지시서와 수급요건 등 실제 제도계약이 필요. 앱이 무허가 의료행위·약 배송·임상 지시를 생성하지 않음.
- 공공 지원·무료 경로를 유료 파트너와 **동등하게 표기**. 이용자 조건에 따른 상업 상품 개인화는 민감정보·차별·이해충돌 검토 전 금지.
- R13 고령 실제 참가자 관찰 NOT RUN. 확인된 공식 프로그램은 케어브릿지랩 실제 제휴/매출이 아님.
