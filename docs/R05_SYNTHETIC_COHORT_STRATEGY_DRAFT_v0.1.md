# R05 준비 — 한국형 합성 환자군·자료 설계 v0.1

- 상태: **DRAFT / 가상 환자 자료 아직 미생성 / 임상 검증 전**
- 기록일: 2026-10-20
- 합의된 방식: **공식 인구·건강·돌봄 통계 + 문헌에서 확인한 임상 패턴 + 직접 창작한 가상 사례**를 함께 사용한다(혼합형 3안).
- 목적: R05 환자군 선정과 R06 서비스 자격·R07 편익·R08 법률/보안 검증에 재사용 가능한 일관된 모의 데이터 기반 구축.

## 1. 합성 환자 원칙

1. 실제 환자 EHR/차트, 실명/연락처/주민번호, 기관 내부자료는 사용하지 않는다.
2. 논문의 **임상적 특성·빈도·정형적 간호 문제**를 참조하되 원문의 재식별 가능한 사례를 그대로 복사하지 않는다. 합성환자 각각은 창작된 독립 케이스다.
3. 공개 통계의 비율은 집단 특성의 **주변분포(marginal)**이다. 개별 항목을 독립 난수로 섞으면 불가능하거나 불합리한 사례가 생길 수 있으므로, **연령·질환·기능·주거·소득·보장유형 등 조건부 관계**를 논문·집계표와 도메인 전문가 의견으로 보정한다.
4. 공식 제도 자격(수급자/차상위/기초연금, 장기요양 등급 등)과 임상 필요도를 분리한다.
5. 국민건강보험/의료급여의 공적 보장 유형, 장기요양 인정 여부, 저소득 지원자격 등을 별도 필드로 보관한다. 단순히 '보험 가입/미가입'으로 축약하지 않는다.
6. 환자군 분포의 현실감과 **임상 예측 모델 검증 가능성은 별개**다. 합성자료에서 높은 정확도가 나와도 실제 임상 성능이라고 주장하지 않는다.
7. 통계·논문에서 얻은 근거는 출처/발표년/모집단/적용 변수/한계를 기록한다. 공개 데이터 라이선스·연구윤리 준수.

## 2. 우선 조사할 데이터 사전(data dictionary)

| 범주 | 후보 필드 | 사용 목적 및 검증 |
|---|---|---|
| 인구·가구 | 연령대, 성별(필요 시), 거주지역, 독거/부부/동거가족, 주돌봄자 | 분포와 돌봄 공백 |
| 경제·보장 | 소득 구간, 공적 급여·의료급여, 기초연금/차상위, 건강보험 자격 분류 | 공식 자격 검토 초안 (확정 금지) |
| 임상 | 진단군, 동반질환, 입원·퇴원 배경, 의학적 추적 필요, 복약 복잡성 | 임상적 개연성과 검토 필요 |
| 기능·간호 | ADL/IADL 제한, 이동, 연하/영양, 상처·처치, 자가관리 수행 | 간호·생활지원 검토 |
| 돌봄 네트워크 | 동거인·보호자의 이용 가능성, 기존 서비스, 방문 가능 여부 | 미충족 돌봄과 의뢰 후보 |
| 퇴원 전환 | 입원/퇴원 일자, 퇴원 예정지, 신청·의뢰·동의 상태, 진료 예약 | 일반/긴급 경로와 날짜 로직 |
| 업무·행정 | 병원 유형, 사업 참여, 지자체 협약, 평가자, 제출서류 상태 | 기관별 처리경로 시뮬레이션 |
| 서비스 | 가정간호/장기요양 방문간호/방문진료/생활지원 구분, 신청 및 수락·완료 상태 | R06 한국형 서비스 매칭 및 양방향 상태 |

값 상태를 `KNOWN / UNKNOWN / NOT_APPLICABLE / CONFLICTING`로 구분하고, 실측·모의·추정값을 `dataOrigin`으로 명시한다.

## 3. 근거 후보

- 국가데이터처 KOSIS: 고령인구·가구형태·지역·소득 등 집계.
- 보건복지부 「2023년 노인실태조사」 결과: 만성질환, ADL/IADL, 돌봄 및 가구 특성 (https://www.mohw.go.kr/board.es?act=view&bid=0027&list_no=1483352&mid=a10503010100&nPage=2).
- 국민건강보험공단 NHIS: 건강보험·장기요양 인정·이용 현황, 통계연보.
- 건강보험심사평가원 HIRA: 진단·진료행위·의료기관 관련 공개 의료통계 (https://www.hira.or.kr/).
- 질병관리청 및 관련 질환 학회 연구: 유병률·임상적 분포·치료 맥락.
- 2026 퇴원환자 통합돌봄 매뉴얼/7월 노인맞춤돌봄 긴급지원: 자격·신청기한·제도 경로.

**의료기관 표본 또는 공개 통계의 범위가 '전체 국민'인지 '병원 퇴원환자'인지 반드시 구분한다.** 일반 고령자 비율을 퇴원환자 유병률로 그대로 적용할 수 없다. 연구용 청구자료를 이용하려면 별도 접근·심의·반출 조건이 있을 수 있다.

## 4. 테스트 환자군 (처음에는 4~6개 정성 사례)

1. 다영역 복합돌봄 사례: 만성질환+복약관리 어려움+사회 지원 부족.
2. 기능제한 우세 사례: 뇌졸중 후 이동/ADL 도움 필요.
3. 사회환경 중심 사례: 임상적 상태 상대적 안정, 퇴원 후 보호·주거 지원 부족.
4. 정보결측 사례: 사회·소득·보호자 상태가 불명확해 자동 추천 보류.
5. 정책 긴급 검토 사례: 65세 이상·퇴원일·수급/기초연금·독거/고령부부 요건을 구분; 지원 결정은 지자체/담당기관.
6. 비대상 또는 낮은 필요 대조 사례: 과도한 경고를 방지하고 다른 사유로 필요한 지원 여부는 열어둠.

초기 케이스의 다양성은 시연·기능 테스트를 위한 것이고 인구 대표성을 뜻하지 않는다. 추후 더 큰 합성 코호트를 설계할 때는 분포와 변수 간 상관관계를 별도로 평가한다.

## 5. 단계별 작업

- R05-A: 최초 환자군의 포함/제외기준·주요 기능·제도 경로 정의.
- R05-B: KOSIS/NHIS/HIRA/노인실태조사 등 통계의 정의·연도·단위·모집단 조사.
- R05-C: 임상 논문·가이드라인을 통한 질환/기능/약료 요구의 공변량·대표 패턴 확인.
- R05-D: 환자별 완전히 창작된 사례 작성, 근거·데이터 출처 등급 표시.
- R05-E: 임상 개연성, 날짜/자격/소득/보장형태 불일치, 누락·예외, 사회적 편향 검토.
- R05-F: R06 연계, R07 비용편익, R08 규제·권한에 테스트 사례 연결.

## 6. 완료 전 금지

- 논문에 나타난 특정 환자의 사연·시간·소득·진료기록을 조합해 사실상 재식별 가능한 공개 케이스 생성.
- 통계적 주변분포를 독립 랜덤 조합하고 '현실과 같은 합성 코호트'로 홍보.
- 환자의 소득·지역·나이만으로 공식 자격·서비스 필요도·치료결과를 확정.
- 합성 데이터 실험 성능을 실제 환자 진단/예후 예측 성능으로 주장.

**이 단계에서 데이터셋과 코드는 생성하지 않는다. R05에서 검토·확정 후 생성한다.**
