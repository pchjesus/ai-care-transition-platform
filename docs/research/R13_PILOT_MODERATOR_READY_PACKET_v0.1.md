## 1. R13 이번 세션의 정확한 범위

우선 **독립 보조기구 경로 목업**의 5개 E과업으로 탐색적 관찰안을 구성. 테스트 참가자는 '실제 환자'가 아닌 일반 고령 사용자나 돌봄경험 성인에게 합성 사례를 설명할 수 있다. 고령자/보호자 표본 1~2명은 결함 발굴용 편의표집일 뿐 성공률 추정이 아니다.
- 기본 연구질문: *공공/급여 및 민간 경로를 구별하고, 확인만 했을 뿐 신청/전송/예약이 이뤄지지 않았음을 설명할 수 있는가?*
- 확장 연구질문(후속 별도): 독립 B, A3 발행 연동 B의 오늘 할 일·일정·알림·PDF·드로어 발견성과 발행/시연/푸시/예약 오인을 구분.
- 의료정보·보험수급·경제적 이익의 실제 사례를 입력받지 않음.
- 가상 목적지/의료지시/정식 연계를 임의 생성하지 않음.

## 3. 참여자용 중립 과업 카드 (초안, 이해를 유도하지 않도록 결과 설명을 사전에 제공하지 말 것)

**시작 멘트:** "이 화면은 실제 병원 정보가 아니라 가상 사례입니다. 치료나 의료기기 선택을 결정하는 도구가 아닙니다. 제가 화면 사용법을 안내하지 않을 테니, 평소처럼 이용해 주세요. 모르는 부분이나 불편한 부분이 생기면 말씀해 주세요. 언제든 쉬거나 그만두실 수 있습니다."

| ID | 읽어줄 과업 | 진행자만 보는 핵심 관찰 |
|---|---|---|
| E01 | "이 가상 사례에서 보조기구를 준비할 방법을 알아봐 주세요." | 초기 행동 발견, 의료진 품목 확인 전제 이해 |
| E02 | "돈을 내고 바로 구매하는 방법 이외에는 어떤 곳에 문의할 수 있을까요?" | 공공·급여/병원·민간 네 경로 발견 |
| E03 | "여기서 장기요양보험을 이용할 수 있다고 확정해 주었나요? 어떻게 이해하셨나요?" | 자격 확정 오인, 행정용어 이해 |
| E04 | "이제 이 화면에서 안내한 일이 어디까지 진행됐다고 생각하시나요?" | 미신청·미전송·미예약 인지 |
| E05 | "글자가 불편하다면 조정해 보고, 이전 단계로 돌아가 주세요." | 글자 확대 버튼·뒤로가기 발견성 |

마무리 비유도 질문: "가장 헷갈린 문구나 버튼은 무엇이었나요?" / "어떤 정보가 더 필요했나요?" / "이 정보를 가지고 실제 문의할 때 어떻게 하실 것 같나요?". 조원은 '복사·인쇄'라는 해결책을 먼저 제시하지 않는다.

## 6. 관찰 뒤 우선순위와 의사결정

- **S0:** 임상정보를 실제 처방, 공공급여를 확정 자격, 예약·전송을 완료로 오인하거나 환자정보 노출 우려 → 안전 검토·해당 과업 중단.
- **S1:** 주요 경로·문의 내용·뒤로가기를 수행하지 못함.
- **S2:** 행정용어·메뉴 발견성·장문·되돌아가기 반복.
- **S3:** 비핵심 시각·간격.
- 오인이 1건 발생해도 심각도와 맥락을 우선 평가한다. 표본 1~2명 결과로 고령자 전체 성공률이나 임상 효과를 일반화하지 않는다.
- 수정 후보는 **가설과 증거/재현·안전 영향·변경 범위·보존해야 할 기능**을 함께 기록하고, 승인 전 기존 B·A1/A2/A3 코드를 변경하지 않는다.
