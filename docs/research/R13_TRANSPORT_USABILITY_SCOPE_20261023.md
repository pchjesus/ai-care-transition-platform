# R13 사용성 파일럿 범위 조정 — 이동 안내 목업

상태: **화면 구현 및 내부 자동화 검증 단계**. 실제 고령 사용자·보호자 연구 NOT RUN.

## 사용자 평가 범위

- 1차: AI/개발자 전문가 휴리스틱 평가(라벨·시각 위계·탭 이동·단계별 선택·알림/예약 오인 가능성).
- 2차: 가능한 경우 소규모 1~2명 비유도 과업 관찰. 탐색적 발견만 기록하며 통계적/임상적 일반화 금지. 사람 대상 데이터를 연구 결과로 활용하려면 지도교수/기관의 관련 연구윤리·동의 기준 확인.
- 기존 5~8명은 권장 탐색 목표일 뿐, 실제 연구의 필수 완료 수치로 주장하지 않음.

## 이동 안내 신규 과업 후보

- T08: 일정 또는 도움 메뉴에서 '병원 길찾기'를 찾아본다. 병원 주소가 확인되지 않은 경우 사용자가 무엇을 할지 말한다.
- T09: '택시 이용 안내'에서 일반 택시/이동에 도움 필요 중 자신에게 맞는 항목을 고르고 다음 준비 행동을 설명한다.
- 안전 이해 확인: "이 화면만 눌러서 택시가 실제로 호출됐다고 생각하시나요?", "병원 주소는 누가 확인한 정보인가요?", "별도의 이동지원 서비스를 실제 예약할 수 있나요?".
- 이번 목업은 **택시 호출, 결제, 요금조회, 배차, 이동지원 차량 연계 기능을 제공하지 않음**. 지도 외부 연결은 의료진이 확인·발행한 목적지만 사용한다. 독립 B는 실제 주소를 생성하지 않는다.

## 판단 보존

- A1/A2/A3, 의료진 승인·발행·개정·철회, 환자정보 저장, 알림 기능의 계약은 변경하지 않음.
- 화면 카드는 큰 터치 영역과 짧은 3단계 안내를 사용하고 실제 연결/미구현 상태를 시각적으로 구별함.
