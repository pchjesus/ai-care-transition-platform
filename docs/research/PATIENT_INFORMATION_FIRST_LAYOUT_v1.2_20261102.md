# CareBridgeLab Patient B — Information-first Layout v1.2 (2026-11-02)

## 문제 및 의사결정
- 사용자가 승인한 그림: 인사말·진료 카드·오늘 할 일 → 진료 상세 → 이동준비 상태 → PDF 자료목록 → 도움받기 서비스 카드로 이어지는 5개 화면.
- v1.1은 기존 화면에 CSS를 입히는 수준이라 시안과 실제 화면 사이에 큰 차이가 있었다. 이번 v1.2에서는 **HTML 렌더 구조를 실제로 교체**한다.
- 기존 포레스트그린 계열, 카드와 버튼 강조, 하단 5개 탭은 보존한다. 문서·이동준비는 기존 실행 가능한 데이터와 작업을 노출한다.

## 실제 적용 범위
1. 독립형 환자 앱 홈: 상단 큰 영웅 배너 제거. '인사말 → 다음 외래(합성 일정) → 3개 할 일 → 안내자료 → 도움받기' 세로 읽기 여정으로 변경.
2. 연동형 환자 앱 홈: 승인된 발행본 항목과 외래 일정만 이용해 동일 구조 렌더링. 환자·입원건/발행/철회 규칙은 변경 없음.
3. 진료 일정: 첫 화면에 발행/예시 외래 카드, 확정되지 않은 항목은 별도 안내.
4. 안내자료: 독립형은 현재 유효 버전에 실제 제공하는 합성 보행보조기 PDF만 문서목록으로 노출. 연동형은 현재 발행본에 실제 포함된 문서만 노출. 용도 설명 및 명시적인 열람 버튼.
5. 이동 준비: 기존 입력 단계는 유지, 최종 단계는 예약 미완료·병원 요청 미전송 상태와 다음 행동을 중심으로 모바일 전체화면 표시.
6. 도움받기: 해당 화면의 주요 항목 카드를 최상단에 배치하고 교통·길찾기 도구는 아래로 이동.
7. CSS는 `patient-v12.css` 독립 추가. v1.1 디테일 스타일은 유지하며 새로운 구조 선택자에만 추가 적용.

## 반드시 보존

- 독립형/연동형의 기존 하단 5탭, 이전·다음·홈, 로컬 알림, 메모, 튜토리얼, 기존 PDF 처리.

- 미확정 일정이나 없는 PDF/의료 연락처를 만들어 표시하지 않는다.
