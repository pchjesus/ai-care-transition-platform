- HTML은 **다운로드 후 브라우저에서 열어야** 발표용 페이지 전환, 확대 화면, 외부 GitHub Pages 앱 연결 등 인터랙션이 가능하다. GitHub 소스 미리보기에서는 실행되지 않는다.
- HTML 안의 환자 앱 독립 시연은 합성 사례이며, 의료진이 발행한 실데이터와 연동된 실제 환자정보가 아니다. 기존 앱의 의료진 승인/발행 경계는 유지한다.
- 업로드 당시의 PDF와 HTML은 **2026-11-10 발표 내용**이므로, 2026-11-12 추가 사용자·교수 피드백의 구현/임상 성과를 담은 개정본으로 오해하지 않는다. 그 발전 방향은 아래 로드맵이 기준이다.
- 공개 저장소의 사업 자료에는 개인정보, 실환자정보, 비공개 병원 문서 및 계약 정보를 올리지 않는다. 대표 성명 등 기존 공개 제출 내용은 유지하되 원본에 포함된 학번으로 새 파일명을 만들지 않는다.

## 업데이트 규칙

1. 새로운 사업계획서나 IR이 확정되면 **위 두 고정 경로를 같은 파일명으로 교체**한다. 각 파일의 Git 커밋 기록이 이전 버전을 보관하므로, 버전별 파일이 누적돼 최신본이 모호해지는 상황을 피한다.
2. 한쪽만 개정할 경우 이 README의 **기준일, 변경사항, 다른 자료와 숫자 불일치 여부**를 갱신한다.
3. 지원금 1,000만 원, 탐색 가격, TAM/SAM/SOM, 2027~2029 재무, 서비스 제휴 수익은 제출본의 수치와 새 변경의 **근거·가정**을 구분해 점검한다. 허가되지 않은 제휴·임상 검증 실적은 만들지 않는다.
4. 주요 사업모델·안전·데이터 계약 변경은 관련 개발 로드맵과 함께 확인한다. 오직 문서 개정으로 기존 운영 앱·`main` 기반 배포 및 `gh-pages` 설정을 변경하지 않는다.
5. 개정 전에는 모든 자료의 개인식별정보·도면·저작권·API키·환자정보 비공개 여부를 확인한다.
