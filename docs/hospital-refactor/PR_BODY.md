## 변경 내용

A3 v0.3에서 PDF 처리 중 환자/실습 전환 시 잘못된 기록에 첨부되고, 손상되거나 다른 탭에서 갱신한 저장값이 덮어써지는 문제를 수정합니다. 평가 이슈 목록이 누락되어도 원자료의 결측·상충을 다시 확인하며, 동일 PDF 재첨부로 승인된 첨부를 복원합니다. 이전 환자 인쇄 내용 잔류와 실습 종료 시 환자 선택 유실도 수정합니다.

첨부 A3 v0.3은 `prototypes/hospital-a3/`에 해시와 함께 그대로 보존하고, 개선안은 `prototypes/hospital-a3-v04/`에 분리했습니다. A2 v0.5와 환자용 v1.3은 변경하지 않았으며 A2/A3 정식 통합은 포함하지 않습니다. 저장 검증만 모듈로 분리하고 승인된 HTML/CSS·평가 규칙은 유지했습니다.

## 검증

- A3 Node 27/27, 실제 HTTP 안전성 13/13 PASS.
- HTTP/standalone 각각 기존 브라우저 32/32 · 기능 44/44 · SYN-001 완주 · 한글 PDF 출력 PASS.
- 6개 화면 폭과 키보드/초점 복귀, 실제 SHA-256·저장 복원·실습 격리·v1 불변/v2 PDF 일치 PASS.
- 변경 전후 24쌍 화면 픽셀 동일, A2/A3 원본 해시 및 세 가지 standalone 빌드 일치 PASS.
- A2 원본 HTTP 테스트는 오래된 기대값으로 FAIL이며 그대로 보존했습니다. 별도 현재 계약 검증은 PASS입니다.
