## 1. 목적과 현재 근거

- 목적: 병원용 A3에서 승인·발행된 합성 계획을 환자용 B가 보여줄 때, 사용자가 **정보를 정확히 찾고 해석하며 도움 요청 경로를 이해하는지** 확인한다.
- 기존 계획: `docs/R00_PATIENT_AND_CAREGIVER_DISCOVERY_v0.1.md`의 T1~T5와 `docs/PATIENT_FIRST_MOBILE_UX_UI_DESIGN_DRAFT_v0.3.md`의 R13/접근성·마이크로카피.
- 기존 자동 테스트: Node/Chromium의 구현·상태·회귀 검증과 **실제 사용자 과업 성공률은 다른 지표**다.
- 비교조건 A: 현재 발행본을 B의 ‘전체 계획/인쇄’에서 출력한 서면 안내.
- 비교조건 B: **동일 발행본**을 표시하는 환자 모바일 웹앱.
- 서로 다른 안내 내용/버전/정보량으로 A와 B를 비교하지 않는다. 스마트폰 vs 종이의 매체 차이까지 함께 작용함을 기록한다.

## 2. 준비와 데이터 안전

1. 동일 브라우저의 현재 시연 웹사이트에서 A3의 `SYN-002`를 **검토 요청→지정 최종 승인자 승인→발행**한다. 계획이 미발행이면 과업 시험을 시작하지 않는다.
2. B에 현재 발행 v1.0이 표시되는지 확인한다. 연구자가 임의로 의학적 숫자·복약량·예약일·연락처를 꾸며 넣지 않는다.
3. 인쇄 조건 A와 모바일 조건 B가 동일한 **발행 ID·버전·승인 텍스트**를 표시하는지 기록한다. 발행본에 실제 예약일·장소가 없으면 그 사실을 정답으로 삼고, 이를 확정된 일정처럼 표현하지 않는다.
4. 테스트 도구는 실명/진단명/연락처/환자번호를 수집하지 않는다. 익명 세션 코드만 사용한다. 실행 결과는 **브라우저 메모리에서만** 보관하고, 사용자가 명시적으로 CSV를 내보낼 때에만 파일이 생긴다. 자동 업로드·자동 저장 없음.
5. 실제 퇴원환자 모집이나 임상연구는 기관 승인, 동의, 개인정보 및 연구윤리 검토 후에만 진행한다. 첫 단계는 연구자/동료의 합성 데이터 파일럿이다.

## 3. 과업과 정답 기준

| ID | 참가자에게 읽는 과업 | 성공 판정(연구자가 발행 텍스트 대조) | 위험한 오해 |
|---|---|---|---|
| T1 | “오늘 복약 관련해 무엇을 확인해야 하는지 찾아 설명해 주세요.” | 승인된 복약 안내를 찾고, 표시되지 않은 용법·용량을 추정하지 않음 | 승인되지 않은 복약 지시를 단정 |
| T2 | “가장 가까운 외래/검사 일정과 장소가 확정됐는지 확인해 주세요.” | 발행본에 명시된 정보만 말하거나 날짜/장소가 없으면 ‘확인 필요’로 판별 | 미확정 일정을 실제 예약으로 오인 |
| T3 | “안내에 있는 주의사항과 연락·문의 경로를 찾아 주세요.” | 발행된 주의·문의 항목을 구분하고 해당 안내를 정확히 찾음 | 텍스트에 없는 임의 응급·연락 지시 |
| T5 | “지금 찾은 내용을 자신의 말로 설명해 주세요.” | 원문과 일치하거나 미확정은 미확정으로 말함. 원문 불명확 시 **내용/설계 문제** 기록 | 미승인 지시 생성, 확인 항목의 수행 완료 오인 |

**선택 과업 T4 (P1 이후):** 서비스 ‘요청/접수/지원계획 확정/제공 시작/중단/종결’을 구별한다. 현재 B에 실제 기관 연계 상태가 없으므로 **지금은 시행하지 않는다**. 로컬 요청 `LOCAL_ONLY`는 기관 접수가 아니다.

## 4. 시험 운영

- 소규모 탐색 파일럿으로 시작한다. 참여자 수를 결과의 대표성·효과 검증으로 주장하지 않는다.
- A→B, B→A 순서를 번갈아 배정해 학습효과를 기록한다. 참가자가 이미 보았던 텍스트·과업으로 재시험하면 **학습효과 가능성**을 명시한다.
- 각 과업은 참가자가 “시작” 신호를 받은 때부터 답변을 마칠 때까지 측정. 종료 시 연구자가 시간·성공 여부·도움 횟수·위험한 오해를 기록한다.
- 성공을 강요하거나 화면 위치를 먼저 알려주지 않는다. 정답 판정이 어려우면 ‘판정 유보’로 기록한다.
- 실제 임상 내용이 아닌 **정보탐색/화면 이해 과업**이다. teach-back 답변을 임상역량이나 실제 복약 이행의 증거로 해석하지 않는다.

## 5. 필수 기록 및 계산

CSV 필드: `session_code,trial_order,condition,task_id,outcome,seconds,help_count,safety_misunderstanding,notes`.
- **성공률:** SUCCESS / (SUCCESS + INCORRECT + NOT_COMPLETED). 판정 유보는 분모에서 제외하고 별도 건수로 기록.
- **소요시간:** 실제 측정된 기록만 집계. 중단/누락 값은 0초로 치환하지 않는다.
- **오해 유형:** 임의 복약·가짜 예약 확정·잘못된 문의 경로·로컬 기관 요청의 실제 접수 오인 등을 따로 기록.
- 과업 조건별 결과는 작은 파일럿에서는 기술통계·관찰 기록 중심으로 비교한다. 유의성, 효과 크기, 환자 안전성 개선을 성급하게 결론 내리지 않는다.
- 정량 목표인 ‘10초 내 찾기’는 기존 문서의 **초기 가설**이며 본 파일럿에서 미리 합격 기준으로 확정하지 않는다.
