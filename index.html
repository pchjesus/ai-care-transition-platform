퇴원 후의 하루까지.

하나의 사이트에서 병원용 업무와 환자용 모바일 화면을 둘러볼 수 있어요. 병원용은 A1 환자 목록 → A2 평가 → A3 검토·승인·발행을 한 화면에서 사용할 수 있어요. 환자용 B는 의료진이 승인·발행한 합성 계획과 같은 사이트에서 연결됩니다. 기존 독립 환자용 v1.3 시연도 계속 이용할 수 있어요.

먼저 화면부터 체험해 봐요.

승인 과정 없이 화면을 살펴본 후, 필요할 때 A3 연동 시연을 진행할 수 있어요.

두 시연은 서로 다른 합성 데이터예요. 예시 내용은 병원에서 발행한 기록이 아닙니다.

연동 시연 안내: 병원용 A3에서 SYN-002를 선택해 검토 요청 → 지정 최종 승인자 승인 → 발행을 진행하고, A3의 「환자용 B 열기」 또는 위 연동 링크를 이용하세요. B 접속 코드는 CARE2026 (시연 코드이며 본인인증 아님). 발행 기록은 같은 브라우저·동일 출처의 로컬 저장소를 사용하며, 다른 기기와 자동 동기화되지 않습니다. 모든 정보는 합성 데이터입니다. 실제 개인정보를 입력하거나 임상·의료업무에 사용하지 마세요.
